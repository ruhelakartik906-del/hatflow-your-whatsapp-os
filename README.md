# Hatflow: Your WhatsApp OS

Design and build a complete premium one-page SaaS homepage for HATFLOW, a WhatsApp Business API + automation + CRM + AI platform by UnknownHat Agency.

Website URL:
https://hatflow.in

Parent / Technology Partner:
UnknownHat Agency
https://unknowhat.com

CORE BRAND POSITIONING:
Hatflow is not just a WhatsApp API tool.
Position it as a complete WhatsApp Business Operating System where businesses can:
- connect WhatsApp
- manage customer conversations
- build no-code chatbot flows
- automate repetitive tasks
- run broadcast campaigns
- manage leads and customers through CRM
- use AI agents
- recover abandoned carts
- integrate ecommerce, CRM, payment, marketing and automation tools
- track conversations, leads and performance from one dashboard

The website must feel premium, technically strong, trustworthy and product-led.
Avoid making it look like a generic digital marketing agency website.
Avoid excessive WhatsApp-green branding.
Use a distinctive premium SaaS visual identity.

VISUAL DIRECTION:
Use:
- Deep navy / almost-black
- Warm ivory / off-white
- Electric blue
- Teal accents
- Very subtle green only where WhatsApp is referenced
- Soft gradients
- Premium glass panels
- Thin borders
- Large clean typography
- Soft shadows
- Rounded 18–24px cards
- High-end SaaS dashboard mockups
- Smooth micro-interactions

Overall reference:
Premium B2B SaaS + modern AI product + enterprise communication platform.

Do NOT copy any competitor website.
Create an original layout.

TYPOGRAPHY:
Use Inter, Manrope or Geist.
Headings should be bold and sharp.
Body text should be clean and highly readable.
Use strong hierarchy and generous whitespace.
